Test Creator Guide

How the Test Creator Works

The Quizora Test Creator provides a complete step-by-step workflow for creating, configuring, scheduling, reviewing, and publishing multiple-choice tests.

Each step collects a specific part of the test configuration. The creator can move through the workflow one step at a time and verify the test before it becomes available to students.

Quick Navigation

Jump directly to any section:

→ Test Information → Import Questions → Review Questions → Marks & Settings → Student Details → Schedule → Instructions → Preview & Publish
Before you begin

Complete the test information, prepare your questions, configure marks and settings, define student details, set the schedule, add instructions, and review the final preview before publishing.

1. Test Information

The Test Information step is the first stage of the test creation process. It allows the test creator to enter the basic information that identifies the examination.

This information can later be displayed on the creator dashboard and on the student portal after the test is published.

Information

  • Test name
  • Subject
  • Category
  • Test description
  • Additional test information
Next step

After entering the basic information, continue to Import Questions.

2. Import Questions

Quizora allows test creators to import a large number of multiple-choice questions using a single Excel file. This avoids manually entering every question into the Test Creator.

The import process uses one Excel file that contains the questions, answer options (A, B, C, D), and the correct answer all in a single spreadsheet.

Import process

1

Prepare your Excel file

Create an Excel file with columns in this exact order: Question, Option A, Option B, Option C, Option D, Correct Answer.

Excel Structure

Row 1 (Headers): Question | Option A | Option B | Option C | Option D | Correct Answer
Row 2: What does CPU stand for? | Central Processing Unit | Computer Personal Unit | Central Program Utility | Control Processing User | A
Row 3: Which of these is an operating system? | Google | Windows | Intel | HTML | B

2

Fill in questions and options

From row 2 onwards, enter one question per row with all four options (A, B, C, D) in their respective columns. Each row contains one complete question.

3

Enter correct answers

In the Correct Answer column, enter A, B, C, or D to mark the correct option. Each answer must be in the same row as its question.

4

Upload the Excel file

Click "Choose Questions & Answers Excel" and upload your prepared file.

5

Automatic validation

Quizora checks the file for missing data, invalid answers, incorrect columns, and incomplete rows.

6

Review imported questions

Once validation is successful, all questions with answers are displayed for review.

Questions & Answers Excel Format

Manual Question Entry

Add one question at a time using the manual entry form. This method is ideal for creating small tests or adding specific questions.

Uploading Your Excel File

After preparing your Excel file with questions and answers, return to the Import Questions step in Quizora Test Creator.

1

Click the upload button

Click Choose Questions & Answers Excel to open the file picker.

2

Select your Excel file

Choose the Excel file (.xlsx or .xls) containing your questions, options, and answers.

3

Automatic validation starts

Quizora reads the uploaded file and checks all columns and data for completeness.

Successful upload

After successful processing, Quizora displays: "✓ Successfully imported [X] question(s) with answers from Excel."

Validation

Validation ensures that the uploaded Excel file contains all required columns and correctly formatted data before questions are added to the test.

Quizora checks

  • Required columns exist.
  • Question text is not empty.
  • Option A is present.
  • Option B is present.
  • Option C is present.
  • Option D is present.
  • Correct answer is available.
  • Correct answer is A, B, C, or D.
  • Answer column exists in the file.
  • Invalid or incomplete rows are detected.
  • All questions have matching answers.
Example validation error

If Question 5 does not contain Option C, Quizora should identify the problem and display an error such as:

Question 5: Option C is missing.

Review Questions After Import

After successful validation, Quizora displays the imported questions in the Review Questions area.

The creator should verify the question text, options, and correct answer before continuing.

  • Check question text.
  • Check Option A.
  • Check Option B.
  • Check Option C.
  • Check Option D.
  • Check the correct answer.
  • Remove incorrect questions if necessary.

4. Marks & Settings

The Marks & Settings section controls how the test is scored and how students interact with the questions.

Marks per Question

The test creator can select the marks awarded for each correct answer.

Available options can include:

  • 1 Mark
  • 2 Marks
  • 3 Marks
  • 4 Marks
  • 5 Marks
  • 10 Marks

Total Marks

Calculation 
Total Marks
=
Number of Questions × Marks Per Question


Example:

50 Questions × 2 Marks
=
100 Total Marks

Test Settings

  • Randomize questions
  • Randomize answer options
  • Allow previous question navigation
  • Negative marking
  • Other examination settings

5. Student Details

The Student Details step defines the information that students must provide before they start the test.

Name and email can be required by default. The test creator can also add additional custom fields depending on the requirements of the examination.

6. Schedule

The Schedule step determines when students can access the test.

Start Date & Time

Select the date and time when the test becomes available to students.

End Date & Time

Select the date and time when the test stops being available to students.

Test Duration

Set the amount of time a student receives after starting the test.

Example Schedule 
Test Name:
NPTEL Practice Test

Start:
10 October 2026 - 10:00 AM

End:
10 October 2026 - 01:00 PM

Duration:
60 Minutes

After the configured availability period ends, the test should no longer be shown as an available test to students.

7. Instructions

The Instructions section allows the test creator to provide rules that students should read before starting the examination.

Example

Test Instructions 
1. Read every question carefully.

2. Select one answer for each question.

3. Do not refresh the browser during the test.

4. Make sure your internet connection is stable.

5. Submit the test before the timer reaches zero.

6. Once the test is submitted, answers cannot be changed.

These instructions can be displayed to students before they enter the examination.

8. Preview & Publish

Preview & Publish is the final stage of the Test Creator workflow. Before publishing, review the complete test configuration to ensure all settings are correct.

Final Review

  • Test name
  • Subject
  • Number of questions
  • Total marks
  • Marks per question
  • Student information fields
  • Start date and time
  • End date and time
  • Test duration
  • Instructions
  • Test settings

Publish

After verifying all information is correct, click Publish Test to make the test available.

The test will become available to students automatically based on the configured start date and time. Students can access the test during the scheduled availability period.

Published Test

Once published, the test appears in the student portal during its scheduled availability period (from start date/time to end date/time). Students can only access the test within this time window.

Platform Features

Quizora provides comprehensive test management and monitoring features to help educators create, manage, and track student assessments effectively.

Student Assignment & Management

Assign tests to specific students using their email addresses. The platform supports two assignment methods:

  • Email Assignment: Add specific student email addresses to assign the test only to those students. Only assigned students can access the test.
  • Access Code Assignment: Generate a unique code that any student can use to access the test.
Adding Students to Published Tests

In the Published Tests page, select a test and view its assigned students. You can add or remove student email addresses even after publishing. Students receive access based on their email registration in the system.

Malpractice Detection & Prevention

Quizora includes built-in malpractice detection to ensure test integrity. The system monitors student behavior during the exam and flags suspicious activity.

🚫 Malpractice Monitoring

What is monitored:
• Tab switching or window changes during the test
• Extended periods away from the test window
• Copy/paste attempts
• Multiple violations trigger automatic test suspension

Teacher Actions:
• View list of students flagged for malpractice
• See specific violation reasons and timestamps
• Option to resume test for students (allows them to continue)
• Malpractice incidents recorded in final reports

Student Results & Reports

Track student performance with detailed reports and analytics. Access comprehensive data for all students who completed the test.

View Completed Student Information

  • Student Profile: Name, email, registration number, school/college
  • Test Performance: Score, total marks, percentage, correct/wrong/unanswered counts
  • Status: Completed, in progress, not started, or malpractice flagged
  • Timestamps: When student started, submitted, or was flagged

Filter & Sort Results

In the Published Tests page, click View Report on any test to see detailed student statistics. Click on statistic cards to filter by:

  • All Assigned Students: Complete list with status for each student
  • Completed: Students who submitted the test with their scores
  • Malpractice: Students flagged for exam violations
  • Not Completed: Students who started but didn't submit, or never started

📥 Download Excel Reports

Export student data to Excel for offline analysis, record-keeping, or sharing with administrators.

Available Excel Downloads

📥 Download All Students
Complete list of all assigned students with their status, scores, and profile information. Includes completed, in progress, malpractice, and not started students.
📥 Download Completed Students
Only students who submitted the test. Includes name, email, score, total marks, percentage, correct/wrong/unanswered counts, school, registration number, and custom fields. Shows if student had malpractice but later resumed and completed.
📥 Download Malpractice Students
Students flagged for exam violations. Includes student details, malpractice reason, and timestamp of the violation. Use this to review and take appropriate action.
📥 Download Not Completed Students
Students who didn't complete the test. Includes those who started but didn't submit, and those who never started. Use this to follow up with students.

Excel File Contents

Each Excel file contains organized sheets with the following columns:

Column Description

Status Completed, In Progress, Not Started, or Malpractice

How It All Works Together

Complete Workflow
  1. Create Test: Add questions manually or import from Excel, configure marks, duration, and settings.
  2. Assign Students: Add student email addresses or generate access code. Set start/end dates and test instructions.
  3. Publish Test: Review all settings and click Publish. Test becomes available at scheduled time.
  4. Monitor Progress: Track how many students started, completed, or were flagged for malpractice in real-time.
  5. Handle Malpractice: Review flagged students, check violation reasons, and decide whether to resume their test or keep it suspended.
  6. View Results: Click View Report to see detailed statistics. Click on stat cards to filter by completion status.
  7. Download Reports: Export filtered student lists to Excel for record-keeping, analysis, or sharing with administration.
  8. Follow Up: Use "Not Completed" list to identify and contact students who didn't finish the test.
💡 Best Practices

Before Publishing:
• Double-check all student email addresses are correct
• Test the exam yourself using a test account
• Review all questions and answers in the preview
• Verify start/end times match your schedule

During the Test:
• Monitor the Published Tests page for live updates
• Check for malpractice alerts periodically
• Be available to resume tests if needed

After the Test:
• Download Excel reports for permanent records
• Review malpractice cases individually
• Follow up with students who didn't complete
• Archive test data before creating next assessment
